# 七区河谷设计

保持一张可步行的大地图，把游玩、采集和经营放在同一段生活里。地图左上是风车游乐园，右上是青杉伐木林，右下靠河是柳荫钓鱼湾；农庄、牧场、小镇和矿洞延续现有玩法。全景与跟随镜头可以切换，地图菜单提供七区步行目的地。

| 区域 | 玩法 | 回到经营系统的收获 |
| --- | --- | --- |
| 向阳农庄 | 七种作物、照料、施肥、品质收成与订单 | 作物、零钱、堆肥 |
| 河湾牧场 | 领养、照料、收取与加工动物产物 | 蛋、奶、毛与加工品 |
| 石溪小镇 | 集市、居民、委托、加工与修建 | 交易、好感与设施 |
| 风车游乐园 | 五次套圈、二十秒打靶、四对翻牌 | 每日前三场成功游戏奖励票券与零钱；票券兑换种子、鱼饵、饲料、堆肥 |
| 青杉伐木林 | 靠近树木挥斧三次 | 四份木材；杉树额外一份树脂；二十四游戏小时后再生 |
| 柳荫钓鱼湾 | 抛竿、咬钩提竿、按住与松开控线 | 河鱼或鲤鱼；与小镇原钓鱼共享鱼饵和每日次数 |
| 北山矿洞 | 挖掘、合成、建造、探索与战斗 | 木材、石料、煤与各类矿物带回河谷 |

美术采用乡村像素比例、温暖草木色、纸色面板和木框。新增条纹摊位、风车轮、彩旗、花箱、林务小屋、原木堆、蘑菇、木栈桥、芦苇、划船和野餐毯。流水、蝴蝶、河鸭、浮漂与挥斧动作丰富场景；系统减少动态效果设置关闭装饰动画，保持玩法正常。

小游戏使用地图上的实际地点和小面板，背景保留所在区域。桌面面板位于右侧，手机面板位于底部；两种输入均支持。游园与钓鱼期间暂停行走及自动世界时间，结束或退出仅推进一次游戏小时。

主页使用新版游戏实际画面，增加七区入口和可点击的地图地名。保留随手记、主题切换和开场，统一草木色、像素装饰与纸木质感。所有视觉素材由本站代码绘制。

地图坐标集中在 `world-data.js`，户外交互集中在 `activities.js`，再生、计分、控线与奖励规则集中在 `activity-rules.js`。所有新区使用原经营存档与库存，避免分散进度。浏览器回归覆盖新增玩法、旧存档迁移与矿洞材料往返。
